The Whitepages Pro API is a U.S. people and property data API. It returns phone
numbers, email addresses, current and historical addresses, property ownership,
and residents. The data comes from public and legal records.

Coverage is United States only, and coverage varies by record. The API is not an
FCRA-regulated product and is not intended for credit, underwriting, employment,
housing, or insurance decisions. See the [Terms of Service](https://www.whitepages.com/terms)
for full details, or contact [api@whitepages.com](mailto:api@whitepages.com) with questions.

## Get your API key

To access the API, you'll need an API key. Sign up for a **free trial** at [whitepages.com/pro-api](https://www.whitepages.com/pro-api).

<Callout type="warn" title="Keep Your API Key Secret">
  Your API key authenticates all requests and tracks usage for billing. Never
  expose it in client-side code or public repositories. If your key is
  compromised, contact [api@whitepages.com](mailto:api@whitepages.com) for a
  replacement.
</Callout>

## Making requests

All API requests require your API key in the `X-Api-Key` header:

```bash
curl 'https://api.whitepages.com/v2/person?name=John%20Smith' \
  --header 'X-Api-Key: YOUR_API_KEY'
```

Responses are returned in JSON format. Each successful request consumes one billable query — see [Billing](/references/billing) for the full policy on which responses are billed.
