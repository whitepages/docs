`GET /v3/property/{identifier}` returns everything on record for one property: physical characteristics, tax assessment, ownership, mortgage history, and current residents.

<Callout type="info" title="Property details, not owner details">
  Ownership arrives in the `ownership_info` block, with no report on how
  complete it is or on which parcel answered. When the owner is the question,
  ask for the owners instead through [Find the
  Owner](/documentation/property-search/find-the-owner).
</Callout>

This is the only call that populates `assessed_info` and
`ownership_info.mortgages`. A search leaves both `null`.

## Three ways to name a property

The identifier's shape selects the lookup. Whitepages identifiers are 11 characters; anything else is read as a parcel number.

| Identifier               | Example       | Resolves to                            |
| ------------------------ | ------------- | -------------------------------------- |
| Property ID (`R` prefix) | `RSAMPLE0001` | One property, or `404`                 |
| Address ID (`A` prefix)  | `ASAMPLE0001` | One property, or `404`                 |
| Parcel number            | `197500-0015` | One property, or `409` with candidates |

```bash title="By property ID"
curl 'https://api.whitepages.com/v3/property/RSAMPLE0001' \
  --header 'X-Api-Key: YOUR_API_KEY'
```

```bash title="By parcel number"
curl 'https://api.whitepages.com/v3/property/197500-0015' \
  --header 'X-Api-Key: YOUR_API_KEY'
```

<Callout type="warn" title="Percent-encode a parcel number">
  A parcel number sits in the URL path, so any character reserved in a path — a
  slash above all — must be percent-encoded. `0342/021` becomes `0342%2F021`.
</Callout>

## Looking up address IDs you already have

Person records, property search results, and event payloads all carry address IDs. Pass one straight to this endpoint to get the property behind it.

Not every address has a property record, so some of these lookups return `404`. Because `404` is never billed here, you can try any address ID you encounter without risking a charge for the misses.

## Billing

| Status | Billable |
| ------ | -------- |
| `200`  | Yes      |
| `404`  | No       |
| `409`  | No       |

Only a record bills. Misses and parcel-number conflicts are free. See [Billing](/references/billing).
