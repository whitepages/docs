`GET /v2/person/` with `phone=` answers **which people match this number**,
ranked, and lets you combine the number with a name or a location. Use it
when a person is the subject and the number is one of your criteria.

<Callout type="info" title="Looking for the number's own facts?">
  If the number itself is the subject — its line type, carrier, or the business
  behind it — use [Phone Search](/documentation/phone-search) instead. That
  guide also returns businesses, which person search cannot.
</Callout>

## Look up a number

```bash title="Request"
curl 'https://api.whitepages.com/v2/person/?phone=2065550142' \
  --header 'X-Api-Key: YOUR_API_KEY'
```

## Combine with name for verification

Verify that a number belongs to a particular person:

```bash
curl 'https://api.whitepages.com/v2/person/?phone=2065550142&name=John%20Smith' \
  --header 'X-Api-Key: YOUR_API_KEY'
```

## Combine with location

Narrow results by adding location filters:

```bash
curl 'https://api.whitepages.com/v2/person/?phone=2065550142&state_code=WA' \
  --header 'X-Api-Key: YOUR_API_KEY'
```

<Callout type="info" title="Matched-first for phone">
  Because the search input was a phone number, the matching phone is pinned to
  position 0 of each record's `phones` list even when it ranks below other
  phones by confidence score. The phone you queried on always appears above the
  cap.
</Callout>

## Choosing between them

| If you want to…                                              | Use                                         |
| ------------------------------------------------------------ | ------------------------------------------- |
| Rank people against the number                               | Reverse Phone Lookup                        |
| Confirm a number belongs to a named person                   | Reverse Phone Lookup                        |
| Combine the number with an address or age filter             | Reverse Phone Lookup                        |
| Know the line type or carrier                                | [Phone Search](/documentation/phone-search) |
| Find the business behind a number                            | [Phone Search](/documentation/phone-search) |
| Get an answer even when nobody is associated with the number | [Phone Search](/documentation/phone-search) |

Each successful lookup bills one unit on either endpoint, whether or not it
found anyone.
