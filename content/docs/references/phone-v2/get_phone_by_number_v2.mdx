title: Look up what is known about a phone number
description: |-
  Retrieve the number's own facts and the parties associated with it.

  Several spellings of one number address this resource, so the
  canonical form goes out in ``Content-Location`` for a caller
  normalizing on their side.

  Parameters
  ----------
  response : Response
      Carries the canonical form back to the caller.
  phone : str
      North American phone number in any common format.
  _query_params : EmptyQueryParams
      Present to reject query parameters; the lookup takes none.

  Returns
  -------
  PhoneLookupV2ResponseDto
      The number's facts and the parties associated with it. A path
      segment that is not a North American number is rejected before
      any upstream call.
